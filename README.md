## Installation

1. Clone this repository:
   ```sh
   git clone https://github.com/Jograph17/Bitlife.Lifesim1.git Bitlife.Lifesim1-new.git

   ```
2. Go to the project folder(important step):
   ```sh
   cd Bitlife.Lifesim1

   ```
3. Install [Python](https://www.python.org/) or Microsoft Store.

## Usage

Run [lifesim.py](lifesim.py) script:
```sh
python3 lifesim.py
```
