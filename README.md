How to install

1. Clone this github repository:
   ```sh
   git clone https://github.com/Jograph17/Bitlife.Lifesim1.git Bitlife.Lifesim1-new.git

   ```
2. Go to the project folder (just in case):
   ```sh
   cd Bitlife.Lifesim1

   ```
3. Install [Python](https://www.python.org/) or from the microsoft Store.



Run [lifesim.py](lifesim.py) script:
```sh
python3 lifesim.py
```
